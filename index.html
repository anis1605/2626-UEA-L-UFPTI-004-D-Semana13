Ciclo Completo de Gestión de Datos Relacionales (CRUD en MySQL)

En esta entrega se conectó la aplicación web con el motor MySQL (ferreteria_db) mediante el módulo conexion/conexion.py y se implementó el esquema relacional con claves foráneas en sql/esquema.sql. Se evidencian las cuatro operaciones fundamentales:

SELECT
Listar con JOIN

Consulta con LEFT JOIN entre productos y proveedores para mostrar el nombre del proveedor relacionado.

INSERT
Agregar Registro

Captura mediante ProductoForm validado y consulta INSERT INTO ... VALUES (%s, ...) con Clave Foránea.

UPDATE
Modificar Registro

Carga previa mediante identificador y actualización precisa con UPDATE ... SET ... WHERE id = %s.

DELETE
Eliminar Registro

Eliminación física con DELETE FROM ... WHERE id = %s, confirmación visual y ejecución de commit().
